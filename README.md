<h1>Availability Checker Lab</h1>

<h2>Description</h2>
This project is a Python utility that automates the process of checking the reachability of multiple IP addresses. Users can provide a .txt file containing a list of targets, and the script outputs which hosts are reachable and which are unreachable. This tool can be used for network reconnaissance, monitoring online asset availability, or supporting OSINT investigations.


<h2>Languages and Utilities Used</h2>

- <b>Python</b> 
- <b>Command Line</b>

<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
